# Sister projects: SAFO and the portable edition

- This repository (SAFO) has a sister project, the portable edition, SHIT (Strategic-Herding-of-IT-Tasks, a separate public repository). The two are at parity on base features: issue and board discipline, local-first model use, review and merge gates, measurement before cutting, token savings.
- They differ in application. SAFO is the maintainer's own custom setup (his boards, tools, machines and guard files). The portable edition is for an enterprise setting: coworkers, any AI tool or none, an optional local model, everything configurable.
- When a fix, measurement, tool or idea lands here, say in the same response whether it belongs in the portable edition and file or link the issue there. A port is configurable: never hard-code the maintainer's hardware, hostnames, vendors, boards or accounts. A change that is SAFO-only says why.
- Never copy private details between the two (the maintainer's boards, hosts, accounts and unfixed security findings stay in each project's private tracker), and a port to the portable edition is configurable.
- Owner order, 2026-11-27 (issue 565).
